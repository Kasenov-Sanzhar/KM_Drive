## О проекте

**KM Drive** — официальное мобильное приложение KM Motors (Kassenov Motors) для владельцев автомобилей. Обеспечивает полный цикл сервисного обслуживания и взаимодействия с автомобилем в рамках цифровой экосистемы концерна.

KM Drive входит в единую экосистему вместе с **KM Connect** (платформа продаж и кастомизации) и работает на собственной технологической платформе **KG-6**.

## Быстрый старт

### Требования
- Flutter SDK ≥ 3.0.0
- Dart SDK ≥ 3.0.0
- Android Studio / VS Code с Flutter-плагином

### Установка

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd km_drive

# 2. Установить зависимости
flutter pub get

# 3. Добавить шрифты в assets/fonts/
# Cormorant Garamond (Light, Regular, Medium, SemiBold)
# DM Sans (Light, Regular, Medium)
# Скачать: fonts.google.com

# 4. Запустить
flutter run
```

### Запуск без шрифтов
Если шрифты не добавлены, приложение запустится с системными шрифтами.
Для подключения шрифтов Google Fonts без файлов:

```yaml
# В pubspec.yaml замените шрифты на:
dependencies:
  google_fonts: ^6.2.1
```

## Принципы разработки

### Clean Architecture
- **Разделение слоёв**: `core` → `data` → `presentation`
- **Dependency Inversion**: `IVehicleRepository` абстрагирует источник данных
- **Single Responsibility**: каждый файл отвечает за одну задачу
- **Immutable Models**: все модели данных `const`-совместимы

### Дизайн-система
- **Цвет**: `KmColors` — единый источник всех цветов
- **Типографика**: `KmTextStyles` — типизированные стили
- **Токены**: `KmRadius`, `KmSpacing` — консистентные отступы
- **Тема**: `KmTheme.dark` — одна точка настройки MaterialApp

### Локализация (Казахстан)
- Все цены в тенге: `KmFormatters.tenge(4900, perMonth: true)` → `4 900 ₸/мес`
- Даты: `KmFormatters.date(date)` → `15 марта 2025`
- Расстояния: `KmFormatters.kilometers(3847)` → `3 847 км`

## Бренд KM Motors

**Kassenov Motors** — казахстанский автомобильный концерн, основанный в Алматы.

**Философия:** «Лучшее качество за минимальную цену» — инженерное совершенство, технологическая продуманность и бескомпромиссная надёжность на 15–20% доступнее традиционных немецких премиум-марок.

**Линейка моделей:**
- KM Adal — компактный премиум (B-класс)
- KM S5 — бизнес-седан (E-класс)
- KM Maya — флагманский седан (S-класс)
- KM Jaqin — премиальный кроссовер
- KM Prime Astre / La Vedette / Fidèle — спортивное подразделение

**Технологии:** Платформа KG-6, цифровые двойники, IIoT, предиктивная аналитика.
